# Lattice Boltzmann

{{ project }} runs lattice Boltzmann methods on meshes adapted by multiresolution.
The header `samurai/schemes/lbm.hpp` provides the schemes, and `demos/LBM` holds programs for advection, shallow water, Euler and Navier-Stokes problems.
{doc}`schemes` walks through one of these programs to show how a scheme is written, run and given boundary conditions.
